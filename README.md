# BasaCheck docs

A reading check is either a microphone recording or an **offline tap**, where the teacher marks missed words and the same engine scores them. Tap checks are labeled Offline tap. They are not Demo Mode, and they still save through the server.

`docs/BasaCheck_PRD.md` is the full product write-up. For the 12-hour hackathon, use only these:

| [04-tech-stack.md](./docs/04-tech-stack.md) | Stack, schema, speech and tap contracts |
